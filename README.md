# Room reservation system

### 📝 Brief description:  
A console Java application for managing hotel rooms and bookings with text file data storage 

### 📌 Task
**Core Functionality**
- add a new room
- change the details of an existing room
- delete a room
- book a room for a visitor
- cancel a room booking
- display a list of all rooms
- display a list of booked rooms
- display a list of available (unbooked) rooms

**Features**
- console (command-line) interface
- data storage in a text file
- room types: standard, Comfort, Suite
- the booking is made for a visitor
- the visitor has the following fields - first name, last name, phone number
